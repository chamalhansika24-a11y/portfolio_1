Microservices / Blockchain Research & Dev Project

Distributed E-Voting System using Microservices & Blockchain

A secure, decentralized electronic voting system eliminating single points of failure by combining passwordless WebAuthn biometric authentication with Ethereum smart contract immutability.

Key Features & Architecture:
  • MS1 (Auth): WebAuthn biometric login (Fingerprint/FaceID), CSV voter batch registration & JWT issuance
  • MS2 (Voting Core): Ethereum Smart Contract execution (Ganache) & strict double-voting prevention
  • MS3 (Results): Decoupled real-time election analytics reading directly from the blockchain
  • Automated DevSecOps CI/CD verification with GitHub Actions & Jenkins
